# Claude Code

Read `AGENTS.md` first.

Source of truth is code, tests, schemas, CI, and ADRs.

Treat `docs/research/` as dated notes, not current truth.

Use `changes/<issue-id>-slug/` only for active multi-step work. Keep it short and remove it from the default branch after merge.

Promote durable knowledge to `docs/decisions/`, `docs/runbooks/`, tests, or code comments.

Project workflow skills live in `.claude/skills/`. Prefer `/start-change`, `/review-change`, `/close-change`, and `/research-note` for repo workflow rituals.
